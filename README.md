# Adaptive Learning Intelligence

A GenAI-powered adaptive learning web app for Engineering/BTech students studying AI/ML, DSA, and core CS subjects.

## What It Includes

- Email/password mock authentication with persistent local learner profiles.
- Today's Plan dashboard generated by Groq from learner progress, weak areas, quiz history, and goals.
- Text-only GenAI study assistant using `groq-sdk` and conversation context.
- Notes upload analysis for `.txt`, `.md`, `.pdf`, and image files from device storage.
- OCR for uploaded images, PDF parsing for documents, then Groq-generated summaries, concept extraction, gaps, and quizzes.
- Adaptive knowledge tracking in `server/data/db.json`.
- Groq-generated quizzes and answer feedback that update weak areas and quiz history.

No voice, speech, camera, webcam, or live capture features are included.

## Setup

1. Install dependencies:

   ```bash
   npm install
   ```

2. Create `.env` from `.env.example` and add your Groq key:

   ```bash
   cp .env.example .env
   ```

3. Start the app:

   ```bash
   npm run dev
   ```

4. Open:

   ```text
   http://127.0.0.1:5173
   ```

## Environment

```text
GROQ_API_KEY=your_groq_api_key_here
GROQ_MODEL=openai/gpt-oss-120b
PORT=8080
CLIENT_ORIGIN=http://127.0.0.1:5173
VITE_API_URL=http://127.0.0.1:8080/api
```

The backend keeps `GROQ_API_KEY` server-side and exposes only app-specific API routes to the React frontend.

## Vercel Deployment

Set these environment variables in Vercel:

```text
GROQ_API_KEY=your_fresh_groq_key
GROQ_MODEL=openai/gpt-oss-120b
```

Leave `VITE_API_URL` empty on Vercel so the frontend calls the same deployment at `/api`.
